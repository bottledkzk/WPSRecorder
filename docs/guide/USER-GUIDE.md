# WPS Recorder 2.3.11 使用说明

## 解压与启动

将 ZIP 整体解压到 Windows 下载目录。课程包运行 `exe_cli/wpsrecorder.exe`，便携试用包运行解压目录内的 `wpsrecorder.exe`。第一次打开可直接录短片，保存位置默认是用户「视频」文件夹中的 `WPSRecorder`。WebView2 Runtime 用于 Studio 界面，加载失败时使用 Qt 工作台。

## 录制第一段视频

1. 在「录制工作台」的源模块点加号，选择屏幕、窗口、区域、摄像头或图片。点击预览下方的目标选择和「设置」，调整当前源的参数。
2. 在混音器打开麦克风或系统播放声并核对电平。需要独立声音轨时选择对应的音频模式。
3. 在「录制设置」选择路径、分辨率、帧率和格式。按码率旁的「默认」恢复推荐值。播放端需要普通 SDR 时在色彩选项选择相应的 SDR 输出。
4. 点「开始录制」。录制时可暂停、继续、截图和打点。结束时点停止，等待状态回到就绪，再到「回看与管理」播放成片。

在场景模块使用加号新建场景，选中场景可编辑名称、调整来源或删除。工作台模块的标题区可拖动换位，分隔线可调整宽度。摄像头作为附加来源时形成画中画，可在实时预览拖动。

可用顶部「预约」建立定时任务。录制时长按时、分、秒输入，留空或写 0 表示手动停录。队列显示冲突与过期状态。在「设置 → 系统快捷键」可设置或留空相应按键。

### 调整录制选区

选择「区域」来源后打开选区。拖动框内部可移动区域，拖边或角可改变范围，确认后录制该矩形。区域坐标按物理像素处理。

## 悬浮条、极简模式和讲解

顶部开关可打开悬浮条。拖动悬浮条可跨屏放置，可收起为小图标，再点击展开。它提供计时、开始停止、暂停、截图和打点，并可切换摄像头或麦克风。悬浮条与讲解条跟随所选主题，极简模式使用最后一次保存的配色。

从「视图 → 极简录制」或托盘进入极简模式，点击 ▶ 录制悬浮条所在显示器，点停止保存。在悬浮条上可以回到工作台。悬浮条的防录效果取决于 Windows 的排除能力。

用「讲解」打开工具条。选择画笔、箭头、矩形、高亮或文字后在目标内容上操作，也可用模糊、实色遮挡、聚光、放大和白板。工具条可以移动、收起和退出。使用讲解效果时可从回看检查成片。

## 回看与管理

可从素材库选择新录像，或打开本地视频。用文件名搜索，点击进度条或右侧打点分节跳转。回看中可以新增打点、编辑名称、设置倍速与音量。无边框全屏中，播放控制闲置约 2.5 秒后收起，移动鼠标重新显示。按 Esc 或点击退出按钮返回原先的窗口状态，播放接着进行。右侧「视频信息」显示文件真实的编码、分辨率、码率、帧率与音轨。异常终止的录像可在可恢复素材里处理。

## 剪辑、字幕与配音

选中素材后点击「进入剪辑」。把播放头定位到切点，点击剪刀后可选中片段删除、重排或导出。选轨后可独立编辑片段，利用联动和锁定控制受影响的轨道。打开吸附后可对齐切点、打点和其他片段边缘。通过「裁剪取景」在画面上调整构图。从「文件 → 打开剪辑工程」可继续工程或草稿。 [可视化剪辑](EDITING.md)

剪辑右侧「字幕与校对」可用选定音轨离线识别，编辑原文或译文、导入导出 SRT、调整字幕样式和位置。「配音与旁白」可选本地 Audio8 或在线服务，核对稿件和读音规则，试听并把结果加到独立音轨。需要直接写进视频的字幕时，在导出选烧录。 [字幕与配音](SPEECH.md)

## 智能助手与主题

在录制和回看打开录屏侧栏，可检索名称与打点、询问录制问题和预览参数建议。剪辑侧栏可基于当前工程给出建议。独立助手工作区可在项目中管理对话和素材。首次使用在线能力，在「设置 → 模型服务」添加自己的服务并检查能力。

在「设置」或「帮助」打开主题画廊，选择 13 套主题中的一套。简体中文和 English 在设置里切换。切换界面语言独立于字幕和配音的语言选择。

## 常见排查

| 现象 | 排查方式 |
| --- | --- |
| 窗口或摄像头访问失败 | 从完整解压后的下载目录启动。摄像头还需检查 Windows 的隐私设置和其他程序占用，窗口需可见且允许捕获。 |
| 双击后出现 Qt 界面 | 查看 Windows 的 Microsoft Edge WebView2 Runtime 是否可用。Qt 工作台可继续使用基础录制。 |
| 回看找不到成片 | 在录制设置查看输出路径，等待封装结束，然后按视频名搜索或打开本地文件。 |
| 长录制空间不足 | 查看当前录制目录剩余空间。停止后检查可恢复素材，再选择新路径或删除测试文件。 |
| 在线助手、翻译或配音报错 | 在模型服务核对用途、协议、模型 ID 与凭据，并运行能力检查。 |
| 从 CLI 查询录制 | 在程序所在目录运行 `wpsrecorder_cli.exe --version` 和 `wpsrecorder_cli.exe --status`。 |
