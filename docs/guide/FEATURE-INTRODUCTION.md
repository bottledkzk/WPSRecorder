# WPS Recorder 2.3.11 功能介绍

WPS Recorder 面向课程讲解、软件演示和操作记录。在 Windows 桌面录好画面和声音后，可以在同一软件中回看打点、剪辑片段、加字幕和旁白，再导出新视频。

## 录制工作台

- **来源与场景。** 可录单个显示器、指定窗口、手动选区、独立摄像头或图片背景。选区用物理像素，支持混合 DPI、跨屏和负坐标。场景可命名和切换，保存主来源与画中画参数。窗口最小化、关闭、受保护或设备断开时，由程序提示受限原因并处理已录片段。
- **实时预览。** 打开录制工作台即可看到当前源。预览下方可以切换目标、打开源属性、缩放、适配窗口和移动放大后的画面。场景、源、混音器、录制设置与录制控制可拖动换位并调整宽度。
- **录制与预约。** 支持开始、停止、暂停继续、3/5 秒等倒计时、截图和打点。可建立多个预约，查看冲突与过期状态。时、分、秒留空或写 0 时由用户结束录制。系统快捷键可单独配置。
- **画质与格式。** 分辨率可跟随来源、选择预设或自定义。Studio 帧率为 30、60、90、144 fps。码率提供与分辨率和帧率联动的默认值，支持手动输入。录制容器为 MP4、MOV、MKV、AVI 和 FLV。可自动选择或显式选择受支持的编码器。支持 SDR、HDR、HDR 转 SDR 和 SDR 转 HDR，实际路径由设备、输出和合成条件决定。
- **混音器与分轨。** 麦克风、系统播放声和其他可用音频设备可选。每路可监看电平、独立调节音量和静音，麦克风可降噪。成片可混音或保留独立声轨。
- **摄像头与画中画。** 摄像头可独立录制，或叠加到主画面中。在预览直接拖动位置，也可设置形状、镜像、尺寸和边框。需要保留摄像头原片时可另存同步 MKV。

### 悬浮条、极简录制与讲解

悬浮条可以拖动、收起和置顶，提供录制、暂停、停止、计时、截图、打点、摄像头、麦克风与工作台入口。悬浮条和讲解条使用当前主题。极简模式通过托盘或「视图」开启，点击播放图标录制控制条所在屏幕，停止自动保存。防录依赖 Windows 的窗口排除能力。

讲解工具包含自由画笔、箭头、矩形、高亮、文字、擦除和撤销重做，还支持聚光、光标跟随放大、白板、刷涂式模糊及矩形实色遮挡。讲解效果在成片中按应用顺序合成。工具条可在桌面拖动和收起。

## 回看与管理

素材库支持打开本地视频、按视频名搜索和按类型筛选。内置播放器支持播放暂停、进度拖动、倍速、音量和无边框全屏。录制打点显示在进度条与右侧分节中，可点击定位、在当前时间新增、直接修改名称。全屏时控制条随鼠标活动显示，退出后保留窗口状态和播放位置。

视频信息可以核对编码、实际分辨率、码率、帧数、帧率、音轨和文件大小。发生异常中止时，可在可恢复素材中查看临时采集文件并另存可用内容。

## 剪辑工坊

- **时间轴。** 一个主视频轨，以及可添加、调整顺序和独立锁定的多条声音轨与字幕轨。在播放头处分割后可保留、删除、拖动重排片段，视频轨间隙自动补齐。支持联动编辑、磁吸到打点、播放头或片段边缘，以及逐帧定位和撤销重做。
- **画面。** 可播放和倍速预览当前工程，调整裁剪框，选择常用或自定义宽高比。可以从当前画面保存静帧、插入自带图片或导入本地图片，并用标记组织章节。
- **声音与字幕。** 可添加外部音频，独立调整音量、定位、切分和混音。字幕支持逐句编辑时间、原文和译文，按轨或片段指定样式和位置。支持 SRT 导入导出。
- **工程与导出。** 工程引用原始素材，支持开关程序时保存草稿、多素材编排和迁移后重新定位素材。导出可选择画质、合并或保留声轨、硬字幕与可选字幕轨。支持分割后的选中片段导出。多素材工程可以从 [CLI](../reference/CLI.md) 按指定码率直接导出硬字幕成片。

## 识别、翻译及配音

离线 Whisper 从选中的音轨生成带时间的字幕。配置服务后可中英互译、逐句重译、使用术语表和 AI 校对。原文、译文或自填稿可以用来生成配音。Audio8 0.1B 本地提供默认音色和普通话女声，在线可以选择配置的语音服务。逐句可试听、调速、改读音规则、重做和加入独立配音轨。章节长稿支持文本导入及旁白期间压低原声。独立语音可导出 WAV。 [字幕与配音](SPEECH.md)

## 智能 AI 助手

录制、回看可以打开录屏侧栏，通过自然语言查找录像或打点，理解报错并预览设置建议。剪辑侧栏使用当前工程生成可审阅的剪辑建议。独立 AI 工作区支持按项目或文件夹组织会话，查看工作区文件、素材和视频预览，还提供适用的 Recorder CLI 工具入口。剪辑方案先预览再应用。长对话可自动压缩上下文，也可用 `/compact`，历史中的原始消息保留。

「设置 → 模型服务」按助手、字幕翻译、视频理解和在线语音配置；按所选服务检查能力。普通录制、回看、剪辑及两项本地语音能力可离线使用。

## 界面和自动化

支持简体中文、English、13 套主题、系统托盘、可配置全局热键和工作区布局记忆。素材库、工程、设备、预览与导出由原生层接入，CLI 和 GUI 共用本地录制服务。命令行覆盖设备、录制、预约、状态、打点、恢复、剪辑、字幕和配音，可通过 JSON 状态接入测试或脚本。 [使用说明](USER-GUIDE.md) · [CLI](../reference/CLI.md) · [2.3.9 验收](../validation/VALIDATION-V239.md)
