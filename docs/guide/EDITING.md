# WPS Recorder 2.3.11 剪辑工坊

在「回看与管理」选录像并点击「进入剪辑」，或从「文件 → 打开剪辑工程」继续已有工程。左侧查看素材、静止画面和章节，中间预览成片，右侧处理字幕、校对、配音与旁白。时间轴在下方。保存工程会保留原始素材引用、剪辑计划和轨道信息。

## 分割和整理片段

| 操作 | 使用方法 |
| --- | --- |
| 定位 | 点击刻度或拖动播放头。左右方向键逐帧定位，空格切换播放和暂停。 |
| 分割 | 在播放头处点剪刀。选中对应轨道时可按轨道编辑。 |
| 片段 | 在分割后选中片段，可删除、拖动调整位置或单独导出。拖动视频片段可换序，视频轨会补齐。 |
| 联动与锁定 | 链条图标控制联动。单轨锁定设在轨道区域。可拖动轨道标题调整顺序。 |
| 磁吸 | 播放头可吸附片段边缘。拖动片段时可对齐打点和其他片段开头或结尾。 |
| 视图 | 可缩放时间轴、横向滚动、倍速预览。工具区提供撤销和重做。 |

时间轴支持一个主视频轨、多条声音轨和多条字幕轨。独立调整音频片段可留出静音；需要缩短成片时，切分并删除视频片段。

## 裁剪、静止画面和章节

点击预览上方的「裁剪取景」调整画面框。可以选择自由比例、常见宽高比或输入自定义比例。素材区域可保存当前画面或导入本地图片并插到时间轴。章节由打点组织，可从列表跳转、调整名称和加入导出。

## 字幕、声音和旁白

在「字幕与校对」选择字幕轨，新增字幕或导入 SRT，也可用本地 Whisper 对指定音轨识别。字幕片段可调整时间，点击进入对应位置。字幕轨与片段支持分别定样式和屏幕位置，同轨的时间片段保持顺序，不同轨可同时显示。译文与校对功能使用配置的模型服务。

声音可添加独立轨并导入文件，再调音量、静音、分割和移动片段。录制时保存的 `.camera.mkv` 可作为独立素材导入。逐句配音、自填旁白和章节长稿可以生成单句音频并试听，确认后可以继续剪辑声音轨。 [语音操作](SPEECH.md)

## 多素材顺排

原生多素材顺排窗口可导入多段视频或单素材工程，逐段保留区间、重排和另存 JSON。素材移走时可用「定位素材」重连经文件指纹核对的原文件。导出使用首段的裁剪尺寸和帧率，其他画幅按比例排入成片。也可以用 CLI 打开与导出同一工程。

### 多素材高光混剪

独立 AI 工作区可按工程或工作区选择素材。配置视频理解服务后输入选段目标，结合现有字幕、标记和画面分析生成候选，先核对依据、选择片段与切点，再应用到工程。自动采样使用 4 FPS 初筛与 8 FPS 局部复核。 [模型配置与能力检验](SPEECH.md#模型服务与能力检验) · [多素材 CLI](../reference/CLI.md#多素材混剪任务)

## 保存、预览与导出

「文件 → 保存当前剪辑工程」将工程写入本机。退出时尚未命名的编辑内容会保留为草稿。导出动作按当时的剪辑计划生成新文件，选择目标路径、编码、码率、混音或分轨，以及烧录字幕或可选字幕。可先从头播放工程，确认切点处画面、字幕和声音同步。已有成片可用新文件名导出。

多素材工程的 CLI 也可直接高码率导出硬字幕。下例使用 26000 kbps 目标码率，融合声音轨，并把两个语言轨的字幕都写入画面。

```bat
wpsrecorder_cli.exe --edit-project --input sequence.json --output demo.mp4 --bitrate 26000 --mix-tracks --burn-captions
```

成片导出读取原素材，预览数据单独处理。2.3.9 的实际多素材导出、声轨和字幕验证见 [验收记录](../validation/VALIDATION-V239.md)。
