# WPS Recorder 2.3.11 验收

2026-11-23 在 Windows x64、2560×1600、150% 缩放环境下，用便携版播放既有实录样片。

## 全屏与悬浮条

- 2.3.10 在麦浪晴光主题下，Windows 窗口已覆盖显示器，播放器仍占约 69% 屏宽。主题的面板定位覆盖了全屏定位。这轮同时检查系统窗口、播放器实际边界和屏幕四角。
- 2.3.11 的 13 套主题均通过回看全屏测试。播放器覆盖视口，标题栏、素材库、打点分节和状态栏隐藏，视频居中并保持原比例。鼠标停在进度条区域时控件能自动收起，移动会重新显示。退出按钮恢复普通窗口的原边界，Esc 恢复最大化，播放继续。
- 剪辑和录制预览在默认深色、麦浪晴光下均通过同样的占屏检查。
- 原生悬浮条的圆角直径受 Qt 控件实际高度约束。新版用深色和浅色主题实测了展开外框的像素边缘，并复测折叠、展开、拖动、录制控制、摄像头和麦克风按钮。sol-theme 的展开圆角和折叠图标也在浏览器内核对。
- Qt 后备播放器的 7 项测试通过，涵盖点按或拖动进度、全屏占屏、退出恢复及播放位置。新版便携 CLI 使用系统 PATH 录制了 3 秒图片源，完整解码 90 帧。
