# 2.0 验证与限制

## 已验证

- Release、Debug 构建成功。新主界面移除侧栏密集表单；设置以六类弹窗收敛，剪辑、导出、最近录制和预约按需打开。
- 枚举两块显示器并实际录制副屏。兼容版 FFmpeg 7.1.1 在现有驱动上成功使用 h264_nvenc；9.0.2 的 NVENC API 13.1 与本机 API 13.0 不匹配，不升级系统驱动。
- 640×360、120fps 输出成功解码 367 帧，视频约 3.058 秒，其中 220 帧为时间轴补帧。此结果证明输出时间轴和编码器可接受 120fps，不证明 120 个独立画面/秒。
- 系统声、麦克风在 MKV 中为两个独立 AAC 轨，标题 mic/system；录制中断续、音频同步与原有容器支持纳入回归。
- 固定遮挡在编码前生效；程序化测试图像中指定遮挡区的解码像素标准差约 0.108。运行中切换白板后指定背景区域像素均值约 251.33。无效遮挡坐标被拒绝。
- 预约在未来时间启动，按有效时长 2 秒自动结束；拒绝过期时间、重叠开始，取消预约有效。
- 七种导出实际由 ffprobe 读取：MP4/MOV/MKV 为 H.264/AAC，WebM 为 VP9/Opus，GIF、M4A/AAC、MP3 分别成立；选区约 2 秒，已有文件拒绝覆盖。音频降噪/清理滤镜已执行，未声称达到专业人声分离或特定降噪评分。
- 离线 whisper.cpp 1.9.5 + 多语言 base 模型在官方公开语音样本上生成 SRT，包含预期词 country；字幕轨成功嵌入 MP4。这不是中文、多人说话或真实课程语音的准确率评测。
- 原有 15 项端到端回归通过，含窗口变化、系统声频谱、麦克风/混音、暂停、区域、MOV/AVI/FLV/MKV、裁剪/拆分/异构合并及反复启停。本轮回归的持续录制为 30 秒，923 帧；暂停期间有效时长变化为 0。
- 新 NVENC 路径独立完成 600 秒持续录制，解码得到 18,000 帧，音视频均为 600 秒，补帧 4。121 次状态采样中最大工作集约 312.09 MiB、最大归一化 CPU 约 3.30%；这些是间隔采样值，不是系统连续峰值。总墙钟约 634.95 秒，包括收尾、采样等待和完整解码。
- 新 GUI 中从开始按钮发起录制，停止后自动加载并播放 67.53 秒文件；无需选择视频。讲解工具成功展开并获得窗口捕获排除能力，但覆盖层被排除出工具截图，因此未用自动鼠标完成全部绘图交互验收；JSON 效果合成已独立验证。
- 完整 H.264/AAC 视频快速转封装为 MOV，保持 90 帧和 3 秒时长；该路径不重新编码。

## 摄像头后续验收

工作区中 `IMFActivate::ActivateObject` 返回 `0x80070005` 的原因已通过同一诊断 EXE 的对照定位：工作区文件继承 Low 完整性标签，进程为 Low（RID 4096）；通过资源管理器解压到桌面普通目录后为 Medium（RID 8192），MF MTA、STA 均成功取得 RGB32 帧。两次对照的 AppContainer 和 TokenIsRestricted 均为 0。工具沙箱直接启动的 CLI 另一次查询为 AppContainer=true、RID 4096，不能将它与普通桌面启动混为一项结果。未调整系统隐私开关或防护软件规则。

2.0 包在普通用户目录的测试窗口能显示摄像头画面；复核代码后确认旧窗口只取一帧，不是持续预览。2.0.1 已改为连续预览并补齐实录验收：10 个短片覆盖仅摄像头、画中画样式/镜像/位置/边框、独立视频轨、双音轨、暂停、切源、重启及后台 CLI，主视频与摄像头轨各 872 帧；GUI 另实录并自动预览成功。详见 [2.0.1 验收](VALIDATION-V201.md)、[摄像头诊断](../reference/CAMERA-DIAGNOSIS.md) 和 evidence/2.0.1。本节保留旧访问拒绝证据的环境边界，不再将其作为当前功能未验收结论。

## 范围

- 1.0 的 602 秒录制证据属于旧 CPU 编码版本，不能替代本次 NVENC 路径的验证。
- 显式指定硬件编码器失败会报错；自动模式依次探测硬件后回退 x264。未在其他 GPU 型号或干净 Windows 虚拟机上验收。
- 标注/马赛克为手动固定区域，不自动识别或跟踪个人信息。独立摄像头视频不含主画面的标注和遮挡。
- 字幕为可选字幕轨，需要播放器开启；不是烧录字幕。模型在本地执行，不上传音视频。
- 预约不唤醒休眠、服务重启不恢复；仅适用于电脑开机且服务运行的任务。
- WebM/GIF 导出采用 CPU 编码。GPU 编码和直接封装不代表任何输入都有固定速度保证。
- 点击视觉提示已实现；点击音效混入尚未实现。进程注入式游戏捕获、公开云链接/平台发布和任意代码插件生态未实现，详见[历史可行性评估](../course/UPGRADE.md)。

原始证据：`evidence/2.0/upgrade-acceptance.json`、`evidence/2.0/regression/acceptance.json`、构建日志。测试媒体和模型保留在源码仓库之外。
