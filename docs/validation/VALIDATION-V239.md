# WPS Recorder 2.3.9 实测与分发

2.3.9 的本机测试在同一台 Windows x64 开发机完成。录制对象包括实体副屏、实际窗口、UVC 摄像头和本机测试画面。版本另有同学异机试用反馈。各项结果的范围见 [课程提交与打包核对](../course/COURSE-CHECKLIST.md)。

## 录制与性能

| 场景 | 输出规格 | 文件时长 | 完整解码帧数 | 录制服务 CPU 采样峰值 |
| --- | --- | ---: | ---: | ---: |
| 实体副屏连续录制 | 1920×1080、60 fps、6000 kbps | 602.20 秒 | 36,130 | 6.15% |
| 窗口 | 1920×1080、60 fps、7000 kbps | 12.00 秒 | 720 | 3.67% |
| 独立 UVC 摄像头 | 1280×720、30 fps、7000 kbps | 6.00 秒 | 180 | 2.04% |
| HDR 副屏转 SDR，带摄像头画中画 | 1920×1080、30 fps、7000 kbps | 9.00 秒 | 270 | 4.76% |
| 实体副屏原生画幅 | 2560×1440、30 fps | 16.00 秒 | 480 | — |

五段使用 NVIDIA H.264 硬件编码。画中画测试同时写出了 9 秒的独立 640×480 摄像头轨。长录使用带动态测试画面的副屏，关闭音频。2026-11-23 启动后每约 5 秒读取状态，共取到 117 组有效样本。CPU 采样中位数 2.03%，采样峰值 6.15%，内存峰值 309.46 MB，补帧 1、遗漏帧位 2。运行时长与文件时长均为 602.2 秒，录制前后都返回空闲状态。CPU 和内存仅对应录制服务进程，FFmpeg、图形界面和整机负载需另测。

本次验证了 CLI 的跨进程启动、状态和停止。空闲状态返回含任务书六个字段的单行 JSON。传入无效录制时长返回退出码 1 和错误消息。定时录制由便携包短测覆盖。

## 工作台、剪辑和语音

- 13 套主题，在 4 组宽度与中英两种语言下检查顶栏几何。104 组均通过重叠与裁切检查。
- 7 项剪辑回归通过，覆盖裁剪与多段合并、时间映射、硬字幕与可选字幕、双轨独立编辑、混音、轨道启停和原素材保护。
- 演示由实际操作实录组成，含极简录制、工作台、窗口、摄像头、画中画、讲解、回看、剪辑、AI 助手和主题速览。使用本机程序合并 14 段实录。旁白使用 Audio8 普通话女声 14 段和 MiniMax 在线女声 3 段，17 条字幕使用实际翻译结果。实测在线录屏助手检索返回实际录像。
- 成片 2560×1440、30 fps、126.767 秒，3,803 帧，含 8 个章节。中文和英文共同烧进画面。抽查静态顶栏 610×66 像素区域，原界面到实录的 SSIM 为 0.984835，实录到成片为 0.9995。测量限该区域与本次导出设置。

## 构建与 ZIP

- 通过 `docs/CMakeLists.txt` 配置并构建 Debug，CLI 返回 2.3.9，GUI 启动并加载四个 Studio 工作区。
- Release 课程包 `gongweichao.zip` 包含 3594 个文件。逐个核对文件 SHA-256、两个固定程序名、运行目录、样片和与定稿 mock 一致的主题样式。
- 同版便携试用包 `WPSRecorder-2.3.9-Windows-x64.zip` 中的程序和运行资源逐项与课程包对应。新目录配合独立用户设置、系统 PATH 解压复测，通过四个工作区加载和普通话女声资源枚举。用 Release CLI 录制图片来源 3 秒，完整解码 90 帧。该复测在本机进行。
- 2026-11-23 收到同学异机试用反馈，2.3.9 便携包使用正常，未发现问题。此条依据用户转述。
- 课程包和试用包的实际大小、摘要及测试数据见 [实测数据 JSON](evidence/2.3.9/release-verification.json)。
