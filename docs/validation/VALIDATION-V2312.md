# WPS Recorder 2.3.12 合并验收

2026-11-26 使用 Windows x64 Release 和本地生成的测试片段复测。2.3.11 用两段 1920×1080 视频合并，默认、指定 `--res 1920x1080` 和使用 `--copy-streams` 均输出 1280×720。

| 2.3.12 用法 | 实测结果 |
|---|---|
| 默认合并两段 1080p | 1920×1080，30 帧完整解码，片段顺序正确 |
| 默认合并混合尺寸 | 640×480 首段确定输出尺寸。带 90° 旋转元数据的 640×480 首段输出 480×640 |
| 混合尺寸指定 `--res 1920x1080` | 1920×1080，4:3 画面等比补黑边，缺失声音补静音 |
| 同规格合并加 `--copy-streams` | 1920×1080，30 个视频包与 50 个音频包的内容哈希和源文件逐个一致 |
| 参数或输入不兼容 | 拒绝流复制与缩放、降噪及不兼容输入的组合，拒绝奇数或无效尺寸与覆盖 |
| 剪切与工程导出回归 | `--trim` 保持 1920×1080。原有剪辑、字幕、混音及源文件保护检查通过 |

合并用例见 [CLI 文档](../reference/CLI.md#剪辑命令) 和 [自动复测](../../tests/merge.py)。本轮的基线、新版及便携包校验见 [验证数据](evidence/2.3.12/merge-verification.json)。
