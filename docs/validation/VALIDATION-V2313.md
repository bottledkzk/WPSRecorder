# WPS Recorder 2.3.13 WorkView 复测

2026-11-27 · Windows x64 Release · FFmpeg 7.1.1

## 修复范围

- 采集与状态。GDI 位图分配或选入失败后清空分配状态，下一帧可重试。WebView2 回退后丢弃旧预览结果。录制状态在锁内按时间窗口采样，连续查询共享最近的 CPU、内存和帧率。预览 JPEG 限制在 1920×1200 内，合成及录制路径继续使用源画面。
- 内置终端和 WebView。内置终端只使用随程序提供的识别引擎，运行后关闭标准输入。WebView 加入内容安全策略，转义来自源、素材和剪辑工程的标识，并在前端明确拒绝超限请求。
- 回看与管理。后台逐项补齐素材的时长和缩略图，录屏助手在文件名、日期或打点命中时提供实际元数据。回看使用单一播放器。移除前释放预览资源，系统回收操作失败时将原文件移动到同盘 `.wpsrecorder-trash`，并显示可恢复路径。
- 导出与剪辑。普通合并继承首段的显示分辨率和帧率，透传显式设置的帧率和目标码率。按轨拼接声音，仅在缺轨的片段补静音。流复制仍保留兼容素材的编码数据，包括旋转信息。外部音频按实际时长加入工程，导出支持 WAV，Studio 可选 NVENC、QSV 和 AMF。
- 配音。Audio8 每批只加载一次模型。各任务使用独立临时目录，退出工作台时可取消合成。
