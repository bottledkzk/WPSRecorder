# 2.0.1 验证记录

日期：2026-11-02。环境：当前 Windows 桌面、本机 UVC 摄像头、RTX 4060 Laptop GPU、兼容版 FFmpeg 7.1.1。摄像头源为 1280×720；验收在普通用户目录的 Medium 完整性进程中运行，没有修改隐私、防护规则或工作区安全标签。

## 摄像头、画中画与分轨

10 项短片均经完整解码计数及像素检查，主视频与旁存摄像头视频各 872 帧：

| 场景 | 主视频 / 摄像头帧数 | 验证 |
|---|---|---|
| 仅摄像头，5 秒 | 150 / 150 | 镜像方向正确；原始轨未镜像 |
| 矩形画中画，6 秒有效时长 | 180 / 180 | 系统/麦克风独立音轨、暂停 1 秒时帧数增长为 0 |
| 镜像圆形，3 秒 | 90 / 90 | 镜像、圆外角落保持背景 |
| 圆角与红色边框，3 秒 | 90 / 90 | 改变位置和尺寸，边框与圆角正确 |
| 图片 → 摄像头 → 画中画，5 秒 | 150 / 150 | 运行中切源与原始轨持续同步 |
| 三次重启，各 1 秒 | 每次 30 / 30 | 释放设备后可再次打开 |
| 后台 CLI 仅摄像头 | 61 / 61 | 2.033 秒，录制与停止正常完成 |
| 后台 CLI 画中画与双音轨 | 61 / 61 | 主画面、原始轨、mic/system 均成立 |

旁存视频为 640×480；主视频为 640×360，均 30fps。依据原始轨重建预期画中画，与成片内部区域的像素平均绝对误差约 3.78～3.99（0～255），错误镜像方向的误差显著更大。角落取样避开 3px 边框和抗锯齿区域，避免把边框误判为形状泄漏。既有旁存摄像头文件会在录制前被拒绝覆盖。

证据：`evidence/2.0.1/camera-final-native.json`、`camera-final-verified.json`。测试代码：`tests/camera_acceptance.cpp`、`tests/verify_camera.py`。不把“文件存在”当作验收，解码、时长、帧数、轨道、画面变化与样式分别核对。

## GUI 与视觉

主窗口保留来源/工具栏、预览、录制控制的分布；更新浅色面板层次、留白、字体、红色主操作、线性图标、下拉箭头、复选框、数值微调和按钮 hover/pressed/disabled/focus 状态。采用 Qt Fusion 和本地矢量资源，没有增加远程素材依赖。主窗口和代表性设置页已实际观察，长设置保留滚动区域。

摄像头连续预览的接收计数从 9 增长到 614，关闭后正常释放。GUI 主按钮发起 1920×1080 录制，停止后生成 28.066 秒、842 帧视频，旁存摄像头视频同为 842 帧；未选择文件即自动进入预览，播放进度实际推进到 5437ms。证据：`evidence/2.0.1/gui-check.json`。

## 回归与修复

- 最终 Release、Debug 构建通过。15 项原有端到端回归在最终二进制上通过；本轮持续录制为 30.833 秒、925 帧。此前 2.0 的 600 秒 NVENC 验收仍属于该次基线，未将本轮短测称为小时级验证。
- 升级检查通过：两屏枚举/副屏实录、120fps 输出时间轴、独立音轨、遮挡解码像素、运行中白板、预约开始/停止/取消、七种导出与音频处理、本地字幕及嵌入。120fps 本次 372 帧含 225 补帧，不代表每秒 120 个独立采样。
- MP4 音轨名称丢失已复现，补 handler_name 后读回 mic/system；两轨时长均为 2.1 秒。内存/CPU 统计计入独立摄像头编码进程。
- 保留修复前的首次录制超时及 GUI 后台停止崩溃记录。摄像头改为异步读帧，统一 MTA 清理；待处理样本先于 MF/COM 关闭释放，CLI 主线程保持 COM 生命周期。修复后原生、后台 CLI 与 GUI 三条路径均验收。
- Low 环境仍会按 Windows 限制返回失败；新消息在约 0.94 秒内给出原因，不误报成功。

证据位于 `evidence/2.0.1/regression-final/`、`upgrade-final/`、`build-summary.json`、`camera-low-error.txt`、`camera-before-timeout.json`、`gui-stop-crash-before.json`。首次升级测试因调用时填错样本路径失败，已用核实的本地路径完整重跑通过，保留此前记录。

## 限制与未完成项

所有剩余范围见 [功能清单](../course/FEATURE-STATUS.md)。真实摄像头验收只覆盖一款设备和短片，未覆盖其他摄像头、驱动、拔插及小时级摄像头/双音轨组合。覆盖层全套手势、热键组合冲突、中文字幕准确率、降噪听感、其他 GPU 和系统主题组合仍未完整验收。进程注入、点击音效、云分享/平台发布、自动隐私跟踪、专业多轨时间线和完整插件生态未实现。

本机摄像头媒体不进入 Git 或体验包。体验包只包含公开测试窗口样片、用户程序、运行库、离线字幕工具/模型、说明及哈希清单。
