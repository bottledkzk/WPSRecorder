# 2.2.4 双语界面验收

默认简体中文。通过「设置 → 界面语言 → 应用语言」可切到 English，英文界面可从 Settings → Interface language 切回。语言保存在用户配置，工作台立即重开；正在录制或倒计时期间暂不切换，剪辑未保存时沿用退出保存确认。

应用文案使用同一份双语目录。简体中文 Qt 字库随可执行文件内嵌，Qt 标准按钮、颜色和文件选择器跟随应用语言，不取决于 Windows 显示语言。设备名、窗口名、文件名、字幕正文、识别语言、配音语言及底层技术日志独立。

原生验收覆盖实际应用重开流程：简体中文 → English → 简体中文；同时验证设置持久化、退出确认的三个按钮、颜色标题及字段、文件名标签、字幕样式、配音试听和典型错误提示。结果见 evidence/2.2.4/language-native.json。

旧版保存的“自动（跟随来源）”分辨率兼容读取，新版保存与语言无关的 auto。剪辑工程、CLI 参数和录制媒体沿用原格式。

Qt 文件选择器的非原生模式参考 [Qt 文档](https://doc.qt.io/archives/qt-5.15/qfiledialog.html)。
