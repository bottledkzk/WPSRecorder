# 2.2.5 全局热键验收

「更多 → 全局热键」中，每行可清除，也可一次清空全部。留空的项不向 Windows 注册，且取消编辑不改变原配置。主窗口按钮仍可操作。

原生测试先注册两个独立的热键，再验证单项清除只释放选中的组合；取消操作保留原设置；全部清空后释放剩余组合。重新打开工作台后，七项仍为空。中英文切换回归通过。见 evidence/2.2.5/native.json。

本次体验包的 sample/screen-recording.mp4 使用已完成的 60.5 秒游戏实录展示成片，保留画中画、静止画面、配音和字幕。成片只放入本地 ZIP，源视频与剪辑工程单独保留，Git 只存源码及文档。
