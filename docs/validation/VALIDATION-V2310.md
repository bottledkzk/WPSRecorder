# WPS Recorder 2.3.10 验收

2026-11-23 使用 Windows x64 Release 版与实际录制样片复测，沿用 [2.3.9 的实录样片和历史性能记录](VALIDATION-V239.md)。

## 回看、工具栏与剪辑助手

| 项目 | 本机结果 |
| --- | --- |
| 回看全屏退出 | Windows 窗口覆盖当前屏幕。退出按钮恢复普通窗口原边界，Esc 恢复最大化，快速进出仍保留原状态，样片继续播放。 |
| 播放控件 | 2.5 秒无交互后自动收起，鼠标停在进度条区域时也有效。移动鼠标重新显示。 |
| 工具栏 | Studio 向两条 Qt 原生工具栏同步 13 套主题。展开尺寸约增加两成，折叠图标为 29 个设计像素。极简模式读取已保存的主题。 |
| 剪辑助手 | 参数栏和输入框的左右边缘对齐。独立 AI 工作区及剪辑工坊侧栏均实测通过。 |

同一台 150% DPI 显示器上，原生悬浮条展开宽度从 627 增至 748 像素。扣除阴影留白后的可见条高从 40 增至 48 像素。原生控件回归也核对了重启配色、浅色与深色切换、折叠图标和 Qt 播放器的 7 项测试。

## 交付

课程包 `gongweichao.zip` 保留 `exe_cli/`、`sample/` 两个目录，两个可执行文件的名称按课程要求。样片沿用 126.767 秒的 1440p 实录，含内嵌中英字幕。

两个 ZIP 各校验 3594 个文件。便携试用包与课程包的程序及依赖一致，完整解压后即可运行。新版 CLI 在仅有系统 PATH 的条件下录制 3 秒 720p30 图片来源，成片完整解码 90 帧。此前同学异机试用反馈对应 2.3.9。本版验证和两个 ZIP 的摘要见 [2.3.10 实测数据](evidence/2.3.10/release-verification.json)。
