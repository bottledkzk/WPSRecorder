# 2.0.2 验收与问题修复记录

本轮针对用户反馈的底部无法选区、录制时缺少摄像头画面、讲解工具栏被画笔覆盖、默认存储目录及多屏兼容性进行修复。验收日期 2026-11-02。证据在 `evidence/2.0.2`，摄像头媒体不上传 Git。

## 显示坐标与选区

旧进程采用 System-Aware。实际主屏为 2560×1600 / 150%，副屏为 2560×1440 / 125%；旧副屏坐标被 Windows 虚拟化为 3072×1728，原点 (3072,-108)。这使录制、框选和跨屏定位出现坐标差异。旧值见 dpi-before.json。

GUI、CLI 和原生测试在 Qt 初始化前改为 Per-Monitor V2，保持 Qt 几何、Windows 鼠标、窗口矩形、显示器枚举和抓屏使用原生像素。修复后副屏为 2560×1440、原点 (2560,-90)，虚拟桌面为 (0,-90,5120,1690)。显示列表同时给出分辨率与缩放，不以某一台电脑的比例写死。

原生界面回归检查选区窗口实际边界与虚拟桌面一致；两块屏幕距离底边 2px 的鼠标命中均落在选区窗口，底部 301×118 选区的全局坐标准确。主屏选区为 (30,1479,301,118)，副屏为 (2590,1229,301,118)。见 ui-native.json。

自动输出按屏幕/区域/窗口启动时的尺寸确定，奇数向下取偶数；手动输出保持可选。界面设计尺寸同时考虑系统 DPI 与可用工作区。未连接的其他分辨率、竖屏、负横坐标和所有缩放组合没有逐台实测；代码支持动态系统矩形，并不据此声称覆盖全部设备。

## 讲解工具栏

画布拥有工具窗口，画布命中 region 减去工具栏矩形，避免画笔吞掉按钮。默认进入操作模式；收起后仍保留操作、展开和退出。Esc 返回操作，再按退出；F8 收起/展开，Ctrl+Alt+Esc 唤回。

原生回归通过：绘图状态下工具栏中心的 WindowFromPoint 命中工具栏；画布 mask 不含工具栏；绘图增加笔迹、撤销恢复、收起保留 3 个按钮、Esc 返回操作及再次退出。见 ui-native.json。这覆盖已报告的输入路由问题；文字/颜色对话框、所有效果和长时间操作仍需进一步人工覆盖。

## 摄像头、画中画、分轨与监看

复用录制进程的采集结果，主画面缩略预览上限 960×540、摄像头 480×360，约 6fps；不再打开第二个设备。GUI 异步读取有界本地 IPC，不写入预览图片文件。暂停标注最后画面，超过两秒无新序号提示等待；结束清空缓存、隐藏悬浮窗并自动播放成片。

本机 USB UVC 摄像头、Medium 完整性进程完成下列十项；独立 FFmpeg 解码与像素检查全部通过，主视频与独立摄像头视频各 874 帧。

| 场景 | 主视频/独立视频帧数 | 预览更新数 |
|---|---:|---:|
| 仅摄像头镜像 | 150 / 150 | 30 |
| 矩形画中画、双音轨、暂停 | 180 / 180 | 36 |
| 圆形镜像画中画 | 90 / 90 | 18 |
| 圆角、位置和边框 | 90 / 90 | 18 |
| 运行中图片→摄像头→画中画 | 150 / 150 | 30 |
| 重启 1 / 2 / 3 | 各 30 / 30 | 各 6 |
| 真实后台 CLI 仅摄像头 | 62 / 62 | 13 |
| 真实后台 CLI 画中画与分轨 | 62 / 62 | 13 |

所有场景的预览 JPEG 可解码、尺寸有界且序号增长。矩形画中画暂停检查帧数增量为 0；双音轨读回 mic/system。镜像、形状、边框和源切换均作像素核对。证据为 camera-native.json 与 camera-verified.json。

第一轮最后一项曾将上一任务已空闲的空预览视作当前有效帧，见 camera-first-native.json。测试改为只统计 active 响应，接口同时明确空闲返回 sequence:0 和空图像；最终十项重跑及独立解码通过，不以第一轮结果替代最终结果。

GUI 另实际录制仅摄像头 1280×720、37.766 秒、1133 帧，观察到实时预览帧号增长，暂停状态为“显示暂停前画面”，继续后推进，停止自动播放。最终 2.0.2 GUI 接入已有 CLI 画中画任务，来源保持 image，主窗口显示合成画面，独立“摄像头 · 实时监看”窗口显示录制状态与隐藏按钮；25 秒后自动保存，主视频和摄像头视频各 750 帧、mic/system 独立音轨，自动播放。主窗口接入服务时不覆盖正在录制的 CLI 场景。

监看窗设置捕获排除成功后才显示；自动化对该窗口的截图得到底层画面，符合排除行为，故不将其截图作为摄像头像素证据。实际摄像头像素检查使用录制进程和成片。没有保存或提交摄像头截图。

## 存储与回归

通过界面将默认目录改为本轮隔离目录，点击完成后文件创建于该目录；新进程打开设置后仍显示相同路径。恢复默认按钮随后还原日常视频目录。配置迁移到用户 LocalAppData，不依赖程序目录可写。详见 gui-check.json 与媒体元数据。

Release/Debug 构建通过。原有 15 项 e2e 回归通过，包含窗口、区域、WASAPI 双声道信号、暂停继续、各种录制容器、裁剪/拆分/异构合并、反复启停及持续录制。本轮持续测试为 30.8 秒 / 924 帧、0 调度补帧；文件名沿用 stability-10min.mp4，但本轮不是 10 分钟测试。

非摄像头升级回归通过：双屏枚举、NVENC 120fps 时间轴、独立音轨、编码前遮挡、运行中场景与白板、预约/取消/拒绝过期与重叠、七种导出/降噪、离线字幕及嵌入。120fps 成片 365 帧，含 185 调度补帧，不能称为 120 个不同画面/秒。升级脚本显式 skip-camera，其 pending 标记由本轮独立十项摄像头证据补充，不能单独称该脚本完成摄像头验收。

没有重跑小时级摄像头分轨测试，也没有验收其他摄像头、AMF/QSV、所有热键冲突或中文嘈杂课程字幕准确率。完整范围见 [功能清单](../course/FEATURE-STATUS.md)。
