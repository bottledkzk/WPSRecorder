# 录屏工作台升级评估

评估日期：2026-11-02。基线为课程仓库 `43f7b1b`。下表是实施范围，不代表已验收；完成后以验证记录为准。

资源：Windows、VS2022、Qt5/C++17、FFmpeg、RTX 4060 Laptop GPU、AMD 610M。可枚举到 USB2.0 HD UVC WebCam，但 DirectShow 打开失败，需要另测 Media Foundation。FFmpeg 9.0.2 的 NVENC 要求 API 13.1，本机驱动提供 13.0，先采用独立兼容版本实测，不修改系统驱动。

| 项 | 可行性与实施范围 |
|---|---|
| 1 UI | 可行。WPS 红色主操作、浅灰工作区、紧凑功能区；录制、讲解、剪辑、工具分组，减少主界面表单堆积。 |
| 2 录制模式 | 屏幕枚举/选屏、区域、独立窗口、仅摄像头、画中画、图片源可行。窗口采集采用独立窗口表面，具体应用可能黑屏/不支持；游戏进程注入暂缓，涉及 DX9/11/12/OpenGL/Vulkan 钩子和反作弊兼容，不能作为通用窗口采集的别名。 |
| 3 分轨 | 可行。MKV/MP4 内系统声与麦克风独立音轨，画中画可另存原始摄像头视频；保持公共时钟，明确播放器通常一次只播放一个音轨。 |
| 4 高帧率/硬编 | 支持到 120fps、NVENC/QSV/AMF 探测、自动回退 CPU；真实采集帧率取决于显示器、CPU 图像合成与总线，参数 120 不代表 120 个不同画面。 |
| 5 定时任务 | 可行。应用服务内预约开始、按有效时长停止、取消和状态。电脑须开机且服务运行；不承诺唤醒休眠。 |
| 6 讲解 | 可行。画笔/箭头/框/高亮/文字、聚光灯、跟随光标放大、白板、点击视觉提示；点击音效需独立混音，分开验证。 |
| 7 隐私遮挡 | 可行。手动框选固定区域、像素化/实色遮挡，合成到编码前的每帧；不承诺自动追踪移动的密码框。 |
| 8 时间轴 | 可行。预览拖动定位，设置入点/出点、切割、片段顺序列表与合并。 |
| 9 字幕 | 可行但需额外模型。离线 whisper.cpp 生成 SRT，可再嵌入导出；识别质量依赖语言、模型和音质，需要人工校对。 |
| 10 降噪 | 可行。FFmpeg 频域降噪、高通/低通和响度处理；不等同于专业人声分离。 |
| 11 摄像头样式 | 可行。矩形/圆角/圆形、镜像、相对位置/大小、边框；取决于摄像头能否成功打开。 |
| 12 格式 | 可行。MP4/MOV/MKV/WebM/GIF，音频 M4A/MP3；GIF 无音频且帧率/尺寸受限。 |
| 13 导出/分享 | 硬编导出、直接复制流可行，不能承诺固定加速比。可导出到用户已配置的同步目录；生成公开云链接和一键发布需服务端/OAuth/服务商 API，暂缓。Windows 无原生 AirDrop。 |
| 14 自动预览 | 已有自动加载路径；补充最近录制列表与完成后定位，验证停止后直接预览。 |
| 15 热键/脚本/插件 | 全局热键、运行中切源、JSON 场景/效果与 CLI 扩展可行；提供版本化声明式场景预设。任意代码插件 ABI、插件市场与隔离体系暂缓，不能称为完整生态。 |

实施顺序：先 UI 与采集/编码基础，再分轨、预约及实时合成，再剪辑/导出/字幕，最后统一 GUI、CLI 和独立包验证。保留原交付 ZIP，升级包单独生成。测试画面、摄像头媒体和模型均不提交课程源码仓库。

依据：[FFmpeg 滤镜文档](https://ffmpeg.org/ffmpeg-filters.html)、[Windows 桌面复制](https://learn.microsoft.com/en-us/windows-hardware/drivers/display/desktop-duplication-api)、[whisper.cpp](https://github.com/ggml-org/whisper.cpp)。
