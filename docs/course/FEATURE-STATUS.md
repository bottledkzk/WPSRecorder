# 2.2.8 历史功能实现与验收清单

本页保留 2.2.8 阶段的验收记录。当前功能和课业完成情况见 [2.3.9 功能介绍](../guide/FEATURE-INTRODUCTION.md) 和 [课程核对](COURSE-CHECKLIST.md)。

2.2.8 增加录前检查、打点、提交档、录屏助手、统一的字幕与配音工作台，以及多素材顺排和智能混剪。新功能的操作方法和实测范围见 [2.2.8 专项验收](../validation/VALIDATION-V228.md)。

|---|---|---|
| 1 简洁 UI | 保持来源选择、工具栏、预览、录制控制的布局；录制设置按类别收纳；支持简体中文和 English，切换持久化及常用弹窗已通过原生检查。浅色面板、红色主操作和本地矢量图标。2.0.2 自动获取逐屏分辨率/DPI，原生坐标统一；主屏 150% 与副屏 125% 的底部选区和工具命中回归通过。 | 没有深色主题；其他实际显示器、所有缩放、主题及辅助技术组合仍待覆盖。 |
| 2 录制模式 | 多屏、固定区域、独立窗口表面、图片源已实录；2.2.6 录制选区可拖边角缩放、移动与确认，混合 DPI 和跨屏原生回归通过；仅摄像头、画中画及实时切源通过 10 项实录解码检查。 | 游戏/应用进程注入未实现；受保护或不支持 PrintWindow 的应用不保证可录。浏览器采用窗口录制，没有独立网页渲染源。 |
| 3 独立分轨 | 系统声与麦克风独立 AAC 轨已实录；MP4 的轨名丢失已修复并读回 mic/system，MKV 已验证。历史验收中 10 个短片的主画面和 .camera.mkv 各 874 帧，双音轨及暂停同步通过。 | 摄像头视频单独保存，未封装为主容器中的第二视频流；摄像头/双音轨组合未做小时级持续录制。 |
| 4 高帧率/硬编 | 本机 RTX 4060 的 NVENC 录制、导出及 600 秒持续录制已验证；120fps 输出时间轴已解码核对。 | 120fps 包含调度补帧，不代表每秒 120 个不同采样画面；其他 GPU、AMF/QSV 路径未完整验收。 |
| 5 定时录制 | 未来时间开始、有效时长停止、拒绝过期/重叠、取消已验收。 | 休眠唤醒、系统重启后恢复、日历周期任务未实现。 |
| 6 讲解模式 | 画笔、箭头、矩形、高亮、文字、聚光灯、光标放大、白板和点击视觉提示；JSON 合成及白板已验证。2.0.2 默认操作模式，工具栏输入孔、画笔时的按钮命中、绘图/撤销、收起和 Esc 返回/退出原生回归通过；F8 与 Ctrl+Alt+Esc 提供唤回。 | 全部绘图手势、文字对话框与长时间交互未完整人工走查；所有全局键冲突仍需设备验证；点击音效未实现。 |
| 7 隐私遮挡 | 固定区域像素化/实色遮挡在编码前合成，解码像素检查通过。 | 自动识别/跟踪敏感内容、高斯模糊未实现；框选交互还需人工完整走查。未处理的独立摄像头轨不带主画面的遮挡。 |
| 8 剪辑 | 2.2.0 同屏画面、缩略图/字幕/独立音频波形时间轴；拖动定位和区间、保留/删除、分割、撤销重做、画面拖框与比例、逐轨声音剪切/静音/音量、JSON 工程、MP4/MOV/MKV 导出。7 项核心解码检查与原生 UI 交互验收通过，原素材不变。多文件合并/批量拆分继续保留。 | 单主视频，可插入静止帧，支持内嵌声音轨及外部音频；不提供多视频层合成、转场、关键帧和复杂模板。预览上限 960×540/30fps，不代表导出降帧。 |
| 9 自动字幕 | 本地 whisper.cpp + 多语言 base；2.2.0 支持指定声音轨识别、手动添加/修改/删除、SRT、预览叠字、字幕烧录或可选字幕轨。2.2.3 增加字幕样式调整及样式导入。第二轨公开语音识别、中文字幕烧录和跨剪切重计时通过。 | 中文课程、多说话人和嘈杂场景准确率未评测；实时字幕和说话人区分不在范围。 |
| 10 音频清理 | FFmpeg 降噪、高低通、导出响度处理执行成功。 | 主观听感、语音保真与定量降噪评测未完成；专业人声分离未实现。 |
| 11 摄像头样式 | 圆形/圆角/矩形、镜像、相对位置/尺寸及边框在真实成片中核对；仅摄像头镜像与未镜像独立轨通过。2.0.2 录制时主窗口合成监看、可隐藏置顶摄像头监看；复用单个设备，暂停状态明确，结束清空缓存。 | 仅本机一款 1280×720 UVC 摄像头，未覆盖其他设备、拔插和各类驱动故障。 |
| 12 多格式 | MP4、MOV、MKV、WebM、GIF、M4A、MP3 实际导出并读回；GIF 限短片，音频只提取首条音轨。 | 未覆盖各种第三方播放器/编辑软件兼容性；WebM/GIF 目前走 CPU。 |
| 13 加速与分享 | 本机 NVENC 导出、完整视频复制流转封装已验证；可保存到用户已有的同步目录。 | 公开云链接、OAuth 网盘分享、一键社交发布、AirDrop 未实现；没有固定导出加速倍数承诺。 |

| 15 热键/脚本/插件 | CLI、本地控制接口、运行中场景切换及 JSON 场景预设；全局热键可自定义或留空，冲突会提示；单项清除、全部清空和重启保留已验收。 | 所有自定义键位及前台应用冲突组合未完整人工走查；没有任意代码插件 ABI、隔离机制和插件市场。 |

## 2.2.0 六项进阶增补

- 悬浮控制条：可拖动、置顶、暂停继续/截图/停止/计时/返回主窗口，最小化主窗口后继续可用；真实按钮驱动实录验收。
- 画中画：主窗口实时合成预览支持直接拖动和右下角缩放；图像内容比例与留白参与坐标换算，独立解码验证前后位置。
- 标注：增加2/3/6/10/16档粗细、整笔橡皮、40步撤销/重做；保留工具输入孔，橡皮不移除隐私遮挡。局部像素擦除不在范围。
- 字幕：选轨/模型/语言移入弹窗，small Q5/base可选，新增日法德西韩意葡俄选项；中英日公开短例已测，法语等未做语言准确率验收。支持取消与中文简体输出。
- 字幕编辑：补充删除操作验收，保留增改、时间轴、重计时与烧录。
- 配音：当时测试 Kokoro 中英 103 音色及 Windows 本地语音（当前试听目录见 [2.2.3 验收](../validation/VALIDATION-V223.md)），调速/音量、试听/WAV、成片时间插入、原声混音/替换；实际输出、时轴和视频流复制已测。未做音质主观评分，不提供声音克隆。
- 详细说明见 [SPEECH](../guide/SPEECH.md)、[课程对照](COURSE-CHECKLIST.md) 与 [2.2.0验收](../validation/VALIDATION-V220.md)。表中旧版874帧、600秒等仍属于对应历史证据。

## 2.1.0 剪辑基线

- 画面、时间轴、字幕与声音设置同窗操作，较多选项通过右侧分页和导出弹窗收拢。
- 剪辑播放改为有界 FFmpeg 解码，播放头跟随实际显示帧；四帧缓存上限，解码等待时暂停声音，切除区间自动跳过。
- 独立声音剪切用静音填补，视频剪切联动声音/字幕，导出时连续拼接；保留原素材并拒绝覆盖输出。
- 修复多段拼接的帧率/画质问题、第二音轨被挤出可视区域、字幕调整时间后连续修改选错项；保留失败与修复后的证据。
- 操作见 [EDITING](../guide/EDITING.md)，验收见 [VALIDATION-V210](../validation/VALIDATION-V210.md)。2.2.0 的六项进阶增补见上节；早期其他未实现扩展不再开发。

## 2.0.2 历史修复与操作文档

- 将旧 System-Aware 坐标改为逐屏 DPI 感知，GUI/CLI/选区统一物理像素；支持原生显示器尺寸和自动来源分辨率。
- 录制进程提供有界的内存缩略预览，主窗口和置顶监看复用设备；空闲清除预览，暂停与等待新帧有明确提示。
- 讲解工具栏由画布拥有，画布移除工具栏命中区域，默认操作并提供收起、退出和唤回。
- 默认保存文件夹增加直达入口、恢复默认和写权限检查；用户配置独立于程序目录，兼容迁移旧设置。
- 详细操作见 [USER-GUIDE](../guide/USER-GUIDE.md)，功能介绍见 [FEATURE-INTRODUCTION](../guide/FEATURE-INTRODUCTION.md)，本轮验收和限制见 [VALIDATION-V202](../validation/VALIDATION-V202.md)。

## 2.0.1 历史修复

- 摄像头单帧测试改为持续刷新，并显示收到的帧数，关闭后释放设备。
- 仅摄像头录制应用镜像选项；旁存原始摄像头轨保持未镜像、未标注的画面。
- 主画面补帧时，同步使用前一帧对应的摄像头画面；避免主画面与旁存视频取自不同采集时刻。
- 旁存摄像头文件已存在时提前拒绝录制，避免录完才发现无法发布。
- MP4/MOV 独立音轨同时写 title 和 handler_name，保留 mic/system 名称。
- 内存/CPU 状态计入额外摄像头编码进程；摄像头采集改为异步请求，设备清理在 MTA 采集线程完成。
- 摄像头最后一个待处理样本在 MF/COM 关闭前释放；CLI 主线程建立完整的 COM 生命周期，修复 GUI 后台服务停止录制时的崩溃。10 项验收包含真实后台 CLI，另验证 GUI 录完自动预览。

本清单中的“已验证”限于当前 Windows 设备和相应记录，不能代替其他设备、驱动、播放器或真实课程内容的验收。

## 2.2.1 操作与预览修复

连续逐帧按帧序号计算；时间轴位置条在1×禁用、放大后可用；全屏播放器自带进度与播放/暂停；主工具栏直接开关悬浮条并同步讲解状态；显示器使用Windows设备名称；独立工作线程加共享内存预览替代常规JPEG轮询。实测和边界见 [2.2.1验收](../validation/VALIDATION-V221.md)。

## 2.2.2 自动颜色与预览

新增实际像素格式探测、HDR系统白电平映射/GPU转换、可选高光/曝光与参考白；两屏及RGBA8/BGRA8/FP16/RGB10 PQ数值测试通过。主/放大预览点击定位、两屏工作区和可选全屏通过。当前屏幕名称无型号硬编码；其他设备、拔插或特殊驱动仍以边界说明为准，见 [本轮验收](../validation/VALIDATION-V222.md)。
